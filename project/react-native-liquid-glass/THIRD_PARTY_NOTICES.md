## Shu Ding — Liquid Glass reference model

The Android `SDF_SCALE_LENS` model is a clean AGSL reimplementation calibrated against the rounded-rectangle SDF and coordinate scale mapping in `shuding/liquid-glass/liquid-glass.js`. No JavaScript runtime code is included in the Android engine. The unmodified reference is loaded by the visual fixture in `reference/liquid-glass.js.fixture.html`.

Source: https://github.com/shuding/liquid-glass
