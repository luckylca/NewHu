# Liquid Glass optical reference fixture

`liquid-glass.js.fixture.html` loads the upstream, unmodified default `liquid-glass.js` from Shu Ding's MIT-licensed repository. The source is kept here only for a reproducible visual fixture and is not part of the Android runtime package. The `?map` query reveals the source displacement canvas for geometry comparison.

Upstream source: https://github.com/shuding/liquid-glass/blob/main/liquid-glass.js

Open this fixture in a browser with network access. The glass uses the upstream script's default 300×200 CSS-pixel size and styles. A fixed color grid, stripe set, text and landscape image remain behind the effect for visual comparison. Add `?capture&width=377&height=896` for device-normalized screenshots; this compensates for the headless browser's outer-window/CSS-viewport mismatch and changes only fixture placement/layout. Add `?map&capture&width=377&height=896` to capture the source displacement map at the same position.
